🎯 PROPÓSITO:

Este proyecto te permite:
1. Debugear PDFs con datos reales
2. Modificar el template visualmente
3. Integrar cambios al servicio fácilmente

═══════════════════════════════════════════════════════════════

⚡ INICIO RÁPIDO (3 pasos):

1. INSTALAR EXTENSIÓN C# (OBLIGATORIO para breakpoints):

   - Abre VS Code
   - Ctrl+Shift+X → Busca "C# Dev Kit"
   - Install → Reinicia VS Code

   Ver: INSTALAR_EXTENSION.md

2. EJECUTAR Y DEBUGEAR:

   - Abre: PdfQuickDebug/Program.cs
   - Edita líneas 16-18 (tus rutas de XML/XSLT)
   - Click en línea 74 (aparece punto rojo 🔴)
   - Presiona F5
   - Inspecciona variables

3. MODIFICAR TEMPLATE:

   - Edita: PdfQuickDebug/Templates/FacturaUbl.cs
   - Cambia algo (ej: Height(48) → Height(80))
   - Ejecuta: dotnet run
   - Ve cambios en PDF

═══════════════════════════════════════════════════════════════

🔧 PARA SOPORTE: INTEGRAR CAMBIOS AL SERVICIO

Después de modificar el template en PdfQuickDebug:

MÉTODO 1 - SCRIPT AUTOMÁTICO (Recomendado):

   .\INTEGRAR_TEMPLATE.ps1

   Esto hace TODO:
   - Copia template
   - Ajusta namespaces
   - Compila servicio

MÉTODO 2 - MANUAL:

   1. Copia archivo:
      FROM: PdfQuickDebug\Templates\FacturaUbl.cs
      TO: code\src\Services.PdfGenerator\Infrastructure\Templates\_1193122070\FacturaUbl.cs

   2. Cambia namespace (línea 10):
      namespace Services.PdfGenerator.Infrastructure.Templates._1193122070;

   3. Cambia using (línea 6):
      using Services.PdfGenerator.Domain.Models;

   4. Compila:
      dotnet build

Ver: PARA_SOPORTE_INTEGRAR.md

🐛 PROBLEMA: "No para en breakpoints"

SOLUCIÓN:
1. Instala C# Dev Kit (ver INSTALAR_EXTENSION.md)
2. Reinicia VS Code
3. Presiona F5 (no el botón Run ▶️)

Si sigue sin funcionar:
- Usa terminal: dotnet run
- Usa Console.WriteLine para ver datos

═══════════════════════════════════════════════════════════════

📋 WORKFLOW COMPLETO:

1. DESARROLLADOR/DISEÑADOR:

   a) Abre PdfQuickDebug en VS Code
   b) Modifica Templates/FacturaUbl.cs
   c) Prueba: dotnet run
   d) Debugea con F5 y breakpoints
   e) Itera hasta obtener resultado deseado

2. SOPORTE (INTEGRAR):

   a) Ejecuta: .\INTEGRAR_TEMPLATE.ps1
   b) Verifica compilación exitosa
